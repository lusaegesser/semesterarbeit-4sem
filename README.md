# DJ Set Archive

Mobile Web-App zum Archivieren eigener DJ-Sets und für Feedback mit Zeitmarken.

## Zwischenprojekt

- Administrator lädt Sets hoch und verwaltet sie.
- Kollegen hören freigegebene Sets auf dem Handy an und kommentieren mit Zeitmarken.
- Möglichst günstiger Betrieb unter einer eigenen Domain.
