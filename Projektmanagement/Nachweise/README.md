# Projektmanagement-Nachweise

[Projektmanagement](../README.md) · [Sprints](../00_Sprints/README.md)

Hier werden bereinigte Kommunikations- und PM-Nachweise abgelegt. Planning,
Review und Retrospektive bleiben im jeweiligen Sprintdokument lesbar; dort wird
auf die zugehörigen Belege verlinkt. Es liegen noch keine zusätzlichen Nachweisdateien vor.

Ein Eintrag nennt Datum, Anlass, Beteiligte, Ergebnis und Folgeaufgaben.
Nachrichtenentwürfe werden als Entwurf bezeichnet. Tatsächlicher Versand,
Rückmeldung und Zugriffsbestätigung werden erst nach Durchführung dokumentiert.
Board-Abbildungen liegen unter [02_Bilder](../02_Bilder/README.md).
